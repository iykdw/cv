\textbf{Smartshelf} \hfill \href{https://github.com/iykdw/smartshelf}{https://github.com/iykdw/smartshelf} \\

\vspace{-6pt}
\begin{itemize}
	\item A Python and FastAPI webapp with SQLite for determining optimal book positions on home bookshelves
	\item Calculates optimal book placement  and tracks borrowing for multiple users using \texttt{Remote-User} header forwarding
	\item Project is containerised using Docker for ease of deployment
	\item Deployed on home server via \texttt{docker compose} using Authelia for authentication and Caddy as a reverse proxy
\end{itemize}

\textbf{Personal Server} \\
\vspace{-6pt}
\begin{itemize}
	\item A server which hosts media, webapps (including Smartshelf), and backups off-site

\end{itemize}

\textbf{Stickerpacker} \hfill    \href{https://github.com/iykdw/stickerpacking}{https://github.com/iykdw/stickerpacking} \\
\vspace{-6pt}
\begin{itemize}
	\item A Python app which efficiently places stickers in a bounded area and generate cut paths
	\item Uses \texttt{matplotlib}, \texttt{imagemagick}, \texttt{pydantic} to determine image boundaries for exporting to Cameo CNC cutter
	\item Deployed in Edinburgh Hacklab with regular use
\end{itemize}
